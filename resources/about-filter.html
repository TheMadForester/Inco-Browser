Inco Filter

Inco's own request filter. It stops requests to ad, tracker and malware hosts before they leave the browser.

What it does

Stops requests to known ad, tracker and malware hostnames (and their subdomains).
Runs in the browser process, not as an extension.
Includes host block lists taken from uBlock Origin Lite (GPLv3): uBlock filters, EasyList, EasyPrivacy, Peter Lowe's list and malware lists.
On by default. Turn it off in Settings.

What it does not

No cosmetic hiding (leftover empty ad boxes can remain).
Network blocking only: no cosmetic filtering, no scriptlets, no path or pattern rules.
Not the full uBlock Origin. On YouTube and heavy sites some ads get through.

Settings

Settings → Privacy → Inco Filter. "Use uBlock Origin block lists" turns the uBlock Origin Lite lists on or off (on by default); the short built-in list stays active. Hosts to never block win over both lists. Extra hosts to block and hosts to never block are set there too. While a vault exists, these two lists are stored encrypted and apply once the vault is unlocked.filter-hosts.txt, filter-ubol.txt
