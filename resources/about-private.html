What private means

Inco is private by default on this computer. Onionize is a separate window that routes through Tor. This is not Tor Browser.

Every normal tab

No browsing history and no session restore.
Always
Cookies and cache are cleared when Inco quits, unless you keep logins.
On by default
Bookmarks stay off until you enable them.
Off by default
Passwords live in an AES-256-GCM vault with a master password, if you want that.
Optional
Chrome extensions (Manifest V3) can be installed from a folder or a .zip/.crx file in Settings > Extensions.
Off by default
Pages cannot reach localhost, link-local or multicast addresses (this stops typical port scans of your own computer). Other LAN addresses are not blocked.
Inco Filter blocks a built-in list of ad/tracker hosts.
On by default

Extensions

Optional and off by default. Install from an unpacked folder or a .zip/.crx file, then switch each one on in Settings > Extensions.
Only Manifest V3 extensions load, and only part of the Chrome extension API exists. Some extensions, for example uBlock Origin Lite, load but do not work fully.
Extensions never load in Onionize windows.
With extensions on, normal windows use a profile on disk. Extension files and their data are stored there unencrypted.

On disk

Without kept logins and extensions, cookies, site storage, visited links and site permissions of normal tabs stay in memory and are gone when Inco quits.
The vault key comes from your master password through Argon2id. While a vault exists, bookmarks, filter lists, search engine and download folder are encrypted with it. The vault locks itself when idle, on sleep and on screen lock.
Kept logins and extensions need a profile on disk. Qt WebEngine stores those cookies and that site data unencrypted on Linux.
For full protection of everything on disk (profile, downloads, swap), use full-disk encryption: LUKS, the “Encrypt my data” option in the Fedora installer.
Data lives in ~/.config/Inco/IncoBrowser/, settings in ~/.config/Inco/IncoBrowser.conf. Onionize keeps Tor state in /run/user/<uid>/inco-browser, gone at logout.

Onionize

Opens a new process that starts bundled Tor and uses SOCKS.
That window can hide your IP from the site. Confirm on check.torproject.org.
It does not use your vault or bookmarks.
It does not make you look like every other Tor user. Fingerprint still exists.
Turning Onionize off closes that window.
The route panel reads guard, middle and exit relays from Tor’s local control port. Anything it cannot read is shown as unknown.

Searches

HTTPS hides the query from a normal firewall. They still see which search engine you used.
A network that intercepts HTTPS can still read the query.
Your search engine sees the words. On a normal tab it can also see your IP.
On a working Onionize window, the search engine sees a Tor exit instead of your IP.
Settings > Search picks the engine: DuckDuckGo (default), Startpage, or a custom address you already had. The new-tab box, the address bar and Onionize windows all use it.
